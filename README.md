# WinTabDock

別々に起動したツールの窓を、1 つの枠にタブでまとめる Windows 用のアプリです。
自作のツールを 1 つずつ起動していくと、タスクバーと窓がどんどん増えて散らかる、を減らすためのものです。

![WinTabDock。上のタブで Todo・メモ・タイマーを切り替える](docs/images/dock.png)

<sub>画面は架空のデモアプリを取り込んだものです。</sub>

- 相手のアプリには手を入れません。窓の枠 (タイトルバー) を外してドックの中に重ね、タブで切り替えます
- タスクバーにはドックのボタンが 1 つだけ残ります
- ドックから外したり、ドックを閉じたりすると、元の窓に戻ります

## ダウンロード

[Releases](https://github.com/lancard-aikawa/WinTabDock/releases) の `WinTabDock-<版>-win-x64.zip` を展開し、`WinTabDock.exe` を起動します (Windows 10 / 11)。

1. `WinTabDock.exe` の隣の `wintabdock.toml` に、まとめたいツールを書きます (書き方は中の見本のとおり)
2. `WinTabDock.exe` を起動し、右上の「+ 起動 / 取り込む」からツールを起動します

```toml
[[tool]]
name = "MyTool"
exe = "C:/Tools/MyTool/MyTool.exe"
```

- 署名の無い exe なので、初回に SmartScreen の警告が出ることがあります (「詳細情報」→「実行」)

## 使い方

- **+ 起動 / 取り込む**: 登録したツールを起動します。起動済みのものは「〇〇 に切り替え」になり、2 つ目は起動しません
  (2 つ目が要るときは一番下の「もう 1 つ起動」)。登録していない窓も「起動中の窓を取り込む」から取り込めます
- **自動取り込み**: 登録したツールは、エクスプローラーからダブルクリックするなど、ドックを通さずに起動しても自動でタブになります。
  ドックを開いたときにもう起動しているものも取り込みます。設定画面などの 2 つ目の窓やダイアログはタブにしません
- **タブの右クリック**: 「ドックから外す (窓は残す)」「ツールを閉じる」。中クリックでも閉じます
- ドックを動かす・大きさを変える・最小化すると、中のツールもついてきます。ツール単体の大きさは、ドックの枠で変えます

## 設定 (右上の「設定 ▾」)

| 項目 | 選べるもの |
|---|---|
| 起動時に開く | 前回開いていたもの (既定) / 選んだものだけ (ツールごとにチェック) / 何も開かない |
| 閉じるときのツール | ドックの × で、毎回たずねる (既定) / 一緒に閉じる / 元の窓に戻して残す |
| ログイン時に起動する | Windows にサインインしたときにドックを起動する (exe の場所を登録するので、移動したら入れ直す) |

- 「一緒に閉じる」では、ツールに × と同じ閉じる操作を送って 5 秒待ちます。保存の確認などで閉じなかったツールは、元の窓に戻して残します
- ドックの大きさ・位置は、次に開いたときに戻ります
- ここで選んだ内容と前回のタブは `%LOCALAPPDATA%\WinTabDock\` に保存します。`wintabdock.toml` は書き換えません

`wintabdock.toml` の設定:

```toml
auto_adopt = true       # ドックの外で起動した登録済みのツールも自動でタブにする
restore_session = true  # 「起動時に開く」をまだ選んでいないときに、前回開いていたタブを開き直す
```

## スマホから使う

スマホのブラウザから、ドックの中のツールを見て操作できます。ドックはスマホの画面の大きさに合わせて変わります (縦・横とも)。
PC とスマホを [Tailscale](https://tailscale.com/) の同じネットワークに入れておく前提です。

1. 「設定 ▾」の「スマホから使う (ブラウザで開く)」にチェックを入れます (初回は、ブラウザ用の画面 noVNC をダウンロードします)
2. 「設定 ▾」の「つなぐ URL をコピー」で URL をコピーし、スマホに送ってブラウザで開きます (ブックマークしておけば次から同じ URL で開けます)

- つないでいる間、ドックは PC の画面の外に移ります。スマホを閉じる (切れる) と元の場所に戻ります
- 遠隔から押せるのは、ツールの中と、ドックのタブだけです (「+ 起動」「設定」は PC で操作します)
- 手元のマウスとキーボードは動かしません。PC の画面がついていなくても使えますが、**ロック中は使えるか確かめていません**
- URL には合言葉が入っています。合言葉を知っている人は誰でも操作できるので、URL は人に渡さないでください。
  漏れたときは「合言葉を作り直す」で前の URL を使えなくできます。インターネットには公開しないでください (Tailscale の中だけで使う)
- 幅が足りないツール (最小の幅があるもの) は、縮めて画面に収めます。文字が小さくなるときは、スマホを横にすると読みやすくなります

待ち受けるアドレスは、Tailscale のアドレスを自動で選びます。変えるときは `wintabdock.toml` に書きます:

```toml
[remote]
host = "100.x.y.z"  # 待ち受けるアドレス (既定: この PC の Tailscale のアドレス)
port = 15900        # ポート (既定: 15900)
```

家の Wi-Fi の中だけで使うなら、`host` に PC の Wi-Fi のアドレス (`192.168.x.x`) を書きます。
この場合、通信は暗号化されないので、同じ Wi-Fi にいる人には URL の合言葉ごと見えることがあります。

初めて待ち受けるとき、Windows のファイアウォールの確認が出たら「プライベート ネットワーク」で許可してください。
許可しなかったときは、Windows がブロックの決まりを作り、以後は確認も出ずにスマホからつながりません
(スマホは「接続しています...」のまま)。そのときは「セキュリティが強化された Windows Defender ファイアウォール」の
「受信の規則」で、WinTabDock (または Python) をブロックしている決まりを消してから、もう一度始めてください。

## うまく扱えないもの

- **管理者として動いている窓**は取り込めません (Windows が普通の権限のアプリからの操作を許さないため)
- **ストアアプリ** (電卓・設定など) は、Windows 共通のプロセスが窓を持つので扱いません
- ドックが異常終了すると、取り込んでいた窓が枠なしのまま残ることがあります。次にドックを起動すると元に戻ります
  (すぐ戻したいときは、ソースから `uv run wintabdock.py --rescue`)
